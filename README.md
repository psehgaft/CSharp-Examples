# CSharp-Examples

Colección de ejemplos de desarrollo en C#/.NET: aplicaciones de consola,
formularios Windows Forms, manejo de archivos, serialización, compresión,
colecciones y una librería de clases. Ideal como material de referencia o
práctica para quien está aprendiendo C#.

## Proyectos incluidos

| Proyecto | Descripción |
|---|---|
| `A.Arriaga_Banco_KJC` | Simulación bancaria: operaciones de banco/cajero. |
| `BancoHRT` | Aplicación de escritorio que simula el cajero de un banco (Windows Forms). |
| `Casa` | Ejemplo básico de consola en C#. |
| `ColeccionesN` | Ejemplos de uso de colecciones en .NET. |
| `DemoCompresion` | Demostración de compresión de archivos/datos. |
| `DemoFileIn` | Ejemplo de lectura/entrada de archivos. |
| `DemoFileInfo` | Ejemplo de uso de la clase `FileInfo` para inspeccionar archivos. |
| `HeberFile1` | Ejemplo de manejo de archivos en C#. |
| `MiLibreria` | Librería de clases de ejemplo (`Persona`, entre otras). |
| `SerializacionGrafica` | Demostración de serialización con interfaz gráfica. |
| `WindowsPersona` | Aplicación Windows Forms con formularios (proyecto `Persona`). |

## Requisitos

- **Visual Studio** (edición Community o superior) con la carga de trabajo de
  *desarrollo de escritorio con .NET*, o el SDK de .NET para los proyectos de consola.
- Los proyectos Windows Forms requieren **Windows**.

## Uso

1. Clona el repositorio:
   ```bash
   git clone https://github.com/psehgaft/CSharp-Examples.git
   ```
2. Abre en Visual Studio el archivo `.sln` del ejemplo que quieras explorar.
3. Compila (`Ctrl+Shift+B`) y ejecuta (`F5`).

Cada carpeta contiene un ejemplo independiente: puedes abrirlo, compilarlo y
modificarlo por separado sin afectar a los demás.
